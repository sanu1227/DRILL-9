# 실제 창 검증 절차

## 준비
```powershell
python DRILL_09/move_character_with_key.py
```
1280×1024 캠퍼스 배경과 중앙의 오른쪽 IDLE 소년이 보여야 합니다.
F5 실행은 `.vscode/launch.json`의 `Drill 9 방향키 이동`을 선택합니다.
다른 컴퓨터에서는 Python 인터프리터 선택 후 `requirements.txt`를 설치합니다.

## 채점 항목
1. 입력 없이 기다립니다. IDLE 8프레임이 반복되는지 확인합니다.
2. 오른쪽과 왼쪽을 각각 길게 누릅니다. 해당 RUN 애니메이션으로 계속 이동해야 합니다.
3. 왼쪽을 눌렀다가 놓고 위·아래로 이동합니다. 왼쪽 방향을 유지해야 합니다.
4. 방향키를 놓습니다. 마지막 방향의 IDLE로 전환해야 합니다.
5. 네 방향 끝과 네 모서리까지 이동합니다. 100×100 캐릭터 영역이 화면 안에 있어야 합니다.

## 입력과 종료
- 대각선 이동 속도는 직선 이동 속도와 같아야 합니다.
- 좌우를 동시에 누르면 수평 이동이 멈추고 하나를 놓으면 남은 방향으로 이동해야 합니다.
- 다른 창으로 전환한 후 돌아옵니다. 키를 다시 누르기 전에는 정지해야 합니다.
- Escape와 창 닫기 버튼으로 각각 정상 종료되어야 합니다.
- 저장소 루트와 `DRILL_09` 폴더에서 각각 실행해도 이미지가 로드되어야 합니다.

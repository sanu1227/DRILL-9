# 검증 결과

검증일: 2026-10-07
환경: Windows, Python 3.14, Pico2D 1.5.1

## 자동 검사
`python -m unittest discover -s tests -v`: 4개 검사 통과.
- 연속 이동, 개별 키 해제, 반대 키 상쇄, 대각선 속도, 수직 이동의 방향 유지.
- IDLE/RUN 네 행, 8프레임 순환, 방향 및 상태 전환 시 프레임 초기화.
- 네 모서리의 전체 캐릭터 영역 제한, 지연 시간 제한, 입력 해제 후 정지.
- 메인 이벤트 연결, 포커스 해제, Escape/QUIT 종료, 예외 시 캔버스 정리, 이미지 누락 안내.
구현 단계마다 Python 구문 컴파일을 수행했다.

## 실제 Pico2D 창
- `Pico2D Canvas (1280x1024)`와 캠퍼스 배경 및 중앙 시작 화면을 확인했다.
- 실제 이미지에서 좌우 IDLE/RUN 행이 표시되는 것을 확인했다.
- 임시 검사 도구로 SDL 키 이벤트를 전달하고 실제 렌더러에 전달되는 좌표와 프레임을 관찰했다.
- 오른쪽 경계 (1230, 512), 오른쪽 위 (1230, 974), 왼쪽 위 (50, 974)를 확인했다.
- 오른쪽을 바라본 상태에서 위로 이동할 때 오른쪽 RUN 행을 유지했다.
- 네 스프라이트 행 모두 프레임 0~7을 사용한 기록을 확인했다.
- 창 포커스를 잃은 후 IDLE로 정지한 것을 확인했다.

## 검증 범위
사용자가 추가 검증 중단을 요청하여 실제 창의 아래쪽 경계와 모든 수동 입력 조합 검사는 종료했다.
아래쪽 경계 및 네 모서리는 자동 검사에서 통과했다. 수동 검사 절차는 `manual-checks.md`에 남겨 두었다.
임시 SDL 검사 도구는 제출 소스에 포함하지 않는다. 기존 수업 예제와 원본 이미지도 변경하지 않았다.

## 개발 이력
초기 커밋 이후 이번 작업은 한글 메시지의 내용이 있는 커밋 33개로 구성했다.
기획서를 구현 전에 작성하고 입력, 화면, 이동, 애니메이션, 경계, 환경, 검증 및 문서를 단계별로 커밋했다.
원격 저장소를 `DRILL-9`로 변경하고 해당 저장소의 `main`에 반영한다.
